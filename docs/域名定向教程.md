# 域名定向（DNS 劫持）教程

> 目标：让局域网内其他设备**零配置**地用 `pan.lan` 之类的好记域名访问你的网盘。

## 一、原理（30 秒看懂）

设备访问 `pan.lan` 时，第一步是问 DNS 服务器："pan.lan 的 IP 是多少？"
- 正常情况：DNS 返回真实 IP → 设备连到真实网站
- 你的服务：命中你配置的映射 → 返回**你的 IP** → 设备直接连到你的网盘

DNS 只管"解析到哪"，设备端完全无感知，所以**不需要安装任何软件、不需要信任任何证书（HTTP 场景）**。

```
设备 → DNS 查询 pan.lan
       ├─ 路由器/公网 DNS → 真实网站（正常上网不受影响）
       └─ 你的 DNS 服务（命中映射）→ 你的 IP → 你的网盘
```

## 二、前提：先把域名加进映射表

1. 登录网盘 → 左侧「管理面板」→「劫持向导」/「域名定向」
2. 域名填 `pan.lan`，IP 填你的局域网 IP（点「自动填本机 IP」）
3. 点「添加映射」

> 域名可以是任意后缀（如 `pan.local`、`mycloud.lan`），但建议用 `.lan` / `.local` 这类非真实后缀，避免与真实网站冲突。

## 三、让设备用你的 DNS（三选一）

### 方式一：路由器设置（推荐，一次配置全家生效）
1. 浏览器打开路由器管理页（常见 `192.168.1.1` / `192.168.0.1`）
2. 找到「DHCP 服务器」→「首选 DNS 服务器」
3. 填入你的 IP，保存
4. 路由器重启后，全家人所有设备自动生效——这就是"一个链接覆盖所有设备"的方式

### 方式二：单台设备手动设置 DNS
| 系统 | 步骤 |
| --- | --- |
| Windows | 设置 → 网络和 Internet → 更改适配器选项 → 右键网卡 → IPv4 属性 → 首选 DNS 填你的 IP |
| macOS | 系统设置 → 网络 → 当前网络 → 详细信息 → DNS → 添加你的 IP |
| Android | WiFi → 长按当前网络 → 修改网络 → IP 设置改静态 → DNS 填你的 IP |
| iOS | WiFi → 点当前网络右侧 ⓘ → 配置 DNS → 手动 → 添加你的 IP |

### 方式三：手机开热点（不动路由器）
本机开热点，DNS 服务端口保持 53，其他设备连该热点并把 DNS 指到本机 IP，适合临时演示。

## 四、验证是否生效（重要）

1. **服务器自测**：管理面板 → 劫持向导 → 「运行一键诊断」，看"DNS 自测"是否通过（期望返回你填的 IP）。
2. **客户端验证**：在另一台设备执行 `nslookup pan.lan`（Windows）或 `dig pan.lan`（Linux/macOS），应返回你的 IP。
3. **查询日志**：管理面板 → 劫持向导 底部的"查询日志"会显示所有来查询的设备。**如果这里一直没有记录，说明设备 DNS 还没指向本机**——回到第三步。
4. **DNS 缓存**：改完 DNS 后设备可能还有缓存，重启 WiFi 或执行 `ipconfig /flushdns`（Windows）。

## 五、HTTPS 与劫持

| 场景 | 结果 |
| --- | --- |
| HTTP 网站 / 你自己的服务 | ✅ 无缝解析，设备直接看到你的内容 |
| HTTPS 网站（如 baidu.com） | ⚠️ 浏览器提示"证书不受信任"，点"高级 → 继续访问"可见内容；安装 CA 证书后可免警告 |
| 想要静默劫持 HTTPS | ❌ 做不到。你的服务器没有对方的证书，这是 TLS 加密的设计保证 |

启用 HTTPS 劫持：管理面板 → HTTPS → 端口填 **443** → 启用并重启。证书会自动包含你配置的全部域名（SAN），访问 `https://pan.lan` 时证书匹配。

**合法边界**：只在你**自己拥有或已获授权**的网络和设备上使用。未经授权劫持他人流量违反中国《网络安全法》和《刑法》第 285/286 条，用于钓鱼盗号属于犯罪。

## 六、常见问题

**Q：改了 DNS 后其他网站打不开了？**
A：本服务会把未匹配的域名自动转发给上游 DNS（默认阿里 223.5.5.5），正常上网不受影响。若打不开，检查上游 DNS 配置（`data/config.json` 的 `dns_upstream`）。

**Q：DNS 服务启动失败？**
A：53 端口需要管理员权限：
- Windows：右键以管理员身份运行 `LanCloud.exe` / `start.bat`
- Linux/macOS：`sudo .venv/bin/python run.py`，或执行 `sudo setcap cap_net_bind_service=+ep .venv/bin/python`

**Q：设备改了 DNS 还是不生效？**
A：DNS 有缓存。重启设备或执行 `ipconfig /flushdns`（Windows）/ `sudo systemd-resolve --flush-caches`（Linux）。

**Q：劫持了但设备打开的是原来的网站？**
A：说明该设备还在用旧 DNS（没指到本机）或域名不在映射表里。用「查询日志」确认设备是否来查询过；确认域名拼写与映射完全一致（含大小写、点）。
