# 常见问题（FAQ）

## 1. 局域网设备打不开网盘？
- 确认手机/电脑与服务器在**同一个 WiFi / 局域网**
- 确认防火墙放行了 Web 端口（默认 8080）：
  - Windows：设置 → 防火墙 → 允许应用通过防火墙，或添加入站规则放行 8080
  - Linux：`sudo ufw allow 8080/tcp`
- 访问地址用 `http://你的IP:8080`

## 2. DNS 服务启动失败？
- 53 端口是特权端口，需要管理员权限（Windows 管理员运行 / Linux sudo 或 setcap）
- 端口可能被占用：`lsof -i :53`（Linux/macOS）查看占用进程
- 失败不影响网盘使用；也可把 DNS 端口改成高端口（`LANCLOUD_DNS_PORT=8053 python run.py`）做测试

## 3. 劫持完全没生效（域名还是打开原网站）？
按顺序排查：
1. **服务器自测**：管理面板 → 劫持向导 → 「运行一键诊断」——若"DNS 自测"失败，说明本机 DNS 服务有问题（端口 / 映射），先修这个
2. **看查询日志**：劫持向导底部日志区。**如果没有任何查询记录，说明其他设备的 DNS 根本没有指向本机**——这是"劫持不生效"最常见的原因，去「接入教程」配置路由器或设备 DNS
3. **确认目标**：劫持 HTTP 网站直接生效；HTTPS 网站会提示证书警告（点继续访问可见）；HSTS 网站（google.com 等）无法劫持
4. **清缓存**：设备执行 `ipconfig /flushdns`（Windows）或重启 WiFi

## 4. 怎么改端口 / 密码 / 注册开关？
管理面板 → 系统信息，或编辑 `data/config.json`：
- `web_port`：网盘端口
- `dns_port`：DNS 端口
- `admin_password`：管理员密码（保存后重启生效）
- `allow_register`：是否开放注册（false 则只有管理员能创建账号）
- `default_quota_mb`：新用户默认配额（0 不限）
- `max_upload_mb`：单文件大小限制（0 不限）

## 5. 怎么给用户开配额 / 批量建号？
管理面板 → 用户管理：
- 单个创建：填用户名 / 密码 / 配额
- 批量创建：每行 `用户名 密码 配额MB`（配额可省略）
- 编辑：改配额、重置密码、禁用 / 启用、分享权限开关

## 6. 数据存在哪？怎么备份？
所有数据在 `data/` 目录（绿色版在 exe 同目录）：
- `data/files/<用户名>/`：网盘文件
- `data/trash/`：回收站
- `data/config.json` / `users.json` / `domains.json` / `mounts.json`：配置与元数据
- `data/certs/`：自签名证书

备份 = 复制整个 `data/` 目录。

## 7. 如何开机自启？
Linux（systemd）：把 `scripts/lancloud.service` 复制到 `/etc/systemd/system/`，修改路径后：
```bash
sudo systemctl daemon-reload
sudo systemctl enable --now lancloud
```
Windows 绿色版：把 `LanCloud.exe` 的快捷方式放进启动文件夹（`Win+R` 输入 `shell:startup`）。

## 8. 分享链接别人打不开？
- 分享链接只能在**同一局域网**内访问
- 如果分享设置了"需要登录"，对方需先注册 / 登录再访问
- 分享过期后自动失效，可重新生成

## 9. 如何把本机文件夹共享给别人？
管理面板 → 共享文件夹 → 填共享名称 + 本机路径（如 `D:\Movies`）→ 添加。
普通用户登录后在左侧「共享文件夹」中即可浏览 / 下载（只读）。

## 10. HTTPS 证书警告怎么消除？
1. 管理面板 → HTTPS → 下载 CA 证书
2. 在设备上安装 CA 证书：
   - Windows：双击 .crt → 安装证书 → 本地计算机 → 受信任的根证书颁发机构
   - Android：设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书
   - iOS：AirDrop 或邮件发送 .crt → 设置 → 通用 → VPN 与设备管理 → 安装 → 打开"完全信任"
3. 安装后访问 `https://pan.lan` 不再警告
