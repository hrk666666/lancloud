# 常见问题（FAQ）

## 1. 局域网设备打不开网盘？
- 确认手机/电脑与服务器在**同一个 WiFi / 局域网**
- 确认防火墙放行了 Web 端口（默认 8080）：
  - Windows：设置 → 防火墙 → 允许应用通过防火墙，或添加入站规则放行 8080
  - Linux：`sudo ufw allow 8080/tcp`
- 访问地址用 `http://你的IP:8080`（不要用 https）

## 2. DNS 服务启动失败？
- 53 端口是特权端口，需要管理员权限（Windows 管理员运行 / Linux sudo 或 setcap）
- 端口可能被占用：`lsof -i :53`（Linux/macOS）查看占用进程
- 失败不影响网盘使用；也可把 DNS 端口改成高端口（`LANCLOUD_DNS_PORT=8053 python run.py`）做测试

## 3. 怎么改端口 / 密码？
编辑 `data/config.json`：
- `web_port`：网盘端口
- `dns_port`：DNS 端口
- `admin_password`：管理员密码（保存后重启生效）
- `allow_register`：是否开放注册（false 则只有管理员能登录）

## 4. 数据存在哪？怎么备份？
所有数据在 `data/` 目录：
- `data/files/<用户名>/`：网盘文件
- `data/trash/`：回收站
- `data/config.json` / `users.json` / `domains.json` 等：配置与元数据

备份 = 复制整个 `data/` 目录。

## 5. 如何开机自启？
Linux（systemd）：把 `scripts/lancloud.service` 复制到 `/etc/systemd/system/`，
修改其中的路径，然后：
```bash
sudo systemctl daemon-reload
sudo systemctl enable --now lancloud
```
Windows：把 `start.bat` 的快捷方式放进启动文件夹（`Win+R` 输入 `shell:startup`）。

## 6. 分享链接别人打不开？
- 分享链接只能在**同一局域网**内访问
- 确认 Web 端口已放行防火墙
- 分享是只读的，接收方无需登录

## 7. 上传大文件失败？
- 检查 `data/config.json` 的 `max_upload_mb`（0 = 不限）
- 网络传输大文件建议用有线连接或 5G WiFi

## 8. 手机端体验如何？
界面已针对移动端自适应：窄屏下侧栏自动变为顶部导航，文件网格自动重排。

## 9. 我可以把项目改成私有仓库吗？
当然。GitHub 仓库页面 → Settings → 拉到最底部 → Danger Zone → Change visibility → 改为 Private。
