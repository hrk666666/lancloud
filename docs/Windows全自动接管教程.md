# Windows 全自动接管教程（方案 C）

> **一句话**：Windows 电脑开着 LanCloud，点一下「一键接管」，
> 同一个 WiFi 下的手机、平板、其他电脑——**一个设置都不用做**，
> 访问被你劫持的域名时，直接打开你的网盘。

---

## 原理（30 秒看懂）

普通「域名劫持」需要每台设备把 DNS 手动指向你，很麻烦。
方案 C 换个思路：**让你的电脑冒充网关**。

1. 你的电脑向全网广播：「网关的 MAC 地址是我」；
2. 其他设备信以为真，把所有上网数据先发给你的电脑；
3. 其中 **DNS 查询**被你的电脑截下 → 交给 LanCloud 解析 → 被劫持的域名直达你的网盘；
4. 其他流量由你的电脑**转交给真实网关** → 看视频、刷网页完全不受影响；
5. 点「停止」后，你的电脑广播真实网关的 MAC，设备几十秒内自动恢复正常。

技术上靠 Windows 内置驱动 **WinDivert**（开源，GitHub ~5k star）
完成抓包与转发，绿色版已内置驱动文件，**全自动安装，免下载、免手动**。

---

## 使用步骤

### 第 1 步：以管理员身份启动

- 右键 `LanCloud.exe` → **以管理员身份运行**
  （驱动安装与抓包必须管理员权限；不用管理员会提示，无法接管）

### 第 2 步：添加劫持目标（只需一次）

- 浏览器打开 `http://127.0.0.1:8080`，登录管理面板
- 「域名定向」→ 添加映射，例如：`pan.lan` → 你的电脑 IP

### 第 3 步：一键接管

- 「劫持向导」→ **方案 C** 区块 → 点 **「一键接管（自动装驱动）」**
- 程序自动完成：安装驱动 → 发现局域网设备 → 开始接管
- 界面会显示**已控制的设备数量**，下方日志实时滚动：
  `DNS 192.168.1.50 查询 pan.lan`

### 第 4 步：验证

- 用手机（连同一个 WiFi，**什么都不用改**）浏览器打开 `http://pan.lan:8080`
- 直接进入你的网盘 = 成功

### 停止

- 点「停止并恢复」→ 网络自动恢复，一切如常
- 直接关掉 LanCloud 也会在退出时恢复（程序退出前自动广播真实网关）

## 常见问题

**Q：提示"需要管理员权限"？**
右键 LanCloud.exe → 以管理员身份运行。

**Q：提示"未获取到网关 MAC"？**
本机先打开一次网页（触发一次联网），再点接管。

**Q：提示"未发现局域网内其他设备"？**
确认手机 / 平板和电脑连的是**同一个 WiFi**，且设备在线。

**Q：杀毒软件弹窗拦截？**
驱动安装需要放行。首次安装会复制驱动文件并创建内核服务，
如被拦截请选择「允许」，然后重新点「一键接管」。
（WinDivert 是国际知名开源驱动，被众多安全软件和抓包工具使用）

**Q：接管后某些设备还是访问不到？**
- 设备有 DNS 缓存：断开 WiFi 重连即可
- 个别系统会校验 ARP：受路由器防欺骗功能影响，可改用「劫持向导」第 3 步的常规 DNS 方案

**Q：会影响正常上网吗？**
不会。只有 DNS 查询被接管，其他流量照常转发；本机不接管时完全无感。

## ⚠️ 法律边界（必读）

ARP 欺骗 / DNS 接管只允许在**你自己拥有或已获明确授权**的网络和设备上使用。
在中国境内，未经授权截获、劫持他人网络流量，可能违反
《中华人民共和国网络安全法》和《中华人民共和国刑法》第 285 / 286 条，
用于盗号、钓鱼等属于犯罪行为。本教程仅用于自有设备与学习研究。
