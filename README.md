# LanCloud · 局域网私有云网盘

一个**中文、美观、开箱即用**的局域网私有云项目：自带完整网盘功能（上传 / 下载 / 预览 / 在线编辑 / 打包 / 分享 / 回收站 / 多用户 / 配额），并提供**域名定向（DNS 劫持）管理界面、一键诊断向导与图文教程**——让局域网内其他设备**零配置**地通过一个好记的域名（如 `pan.lan`）访问你的网盘。支持**自签名 HTTPS**，并可将**本机任意文件夹**挂载为共享库供他人浏览下载。

> 数据只存在你自己的设备上，不上传任何第三方服务器。

## ✨ 功能特性

### 网盘（私有云）
- ✅ 文件上传（拖拽、多文件、进度条）、下载、在线预览
- ✅ 图片 / 视频 / 音频 / 文本 / PDF 在线预览（视频支持拖动进度）
- ✅ **在线文本编辑**（保存即生效）
- ✅ 新建文件夹、重命名、移动、搜索
- ✅ **文件夹 / 文件打包 zip 下载**
- ✅ 分享链接：免登录 / **强制登录** / **有效期**，用户级分享权限开关
- ✅ 回收站：误删可恢复，彻底删除 / 一键清空
- ✅ 多用户：注册登录、独立目录、**存储配额**（可全局默认 + 单用户设置）

### 管理面板
- ✅ **用户管理**：单独创建 / 批量创建账号、禁用 / 启用、重置密码、存储配额、分享权限
- ✅ **共享文件夹（挂载）**：把本机任意目录共享给局域网用户浏览 / 下载（只读）
- ✅ 开放注册开关、新用户默认配额、单文件大小限制
- ✅ 服务状态卡片、DNS 启停、HTTPS 开关

### 域名定向（"劫持"）
- ✅ 内置 DNS 服务（UDP + TCP），把任意域名解析到你指定的 IP
- ✅ **劫持向导**：分步指引 + **一键诊断**（自动自测映射是否生效）+ **实时查询日志**（可确认局域网设备是否真的来查询了）
- ✅ 未匹配域名自动转发上游 DNS，**不影响正常上网**
- ✅ **方案 C（进阶）**：`scripts/arp_hijack.py` ARP 欺骗脚本——设备**零配置**自动接管全网 DNS（Linux，见 [docs/ARP欺骗教程.md](docs/ARP欺骗教程.md)）
- ✅ 图文教程：路由器 / 设备手动 / 手机热点 / ARP 四种接入方式
- ✅ 明确标注 HTTPS 限制与法律边界（见下方"重要说明"）

### 自签名 HTTPS
- ✅ 自动生成本地 CA + 服务器证书（SAN 自动覆盖局域网 IP 与全部域名映射）
- ✅ 网盘同时支持 HTTP + HTTPS 双服务
- ✅ 劫持 HTTPS 站点时可显示你的内容（浏览器有证书警告；安装 CA 证书后免警告）
- ✅ 管理面板一键开关、下载 CA 证书、安装教程

### 绿色版（Windows）
- ✅ PyInstaller 打包，**解压即用**，双击 `LanCloud.exe` 启动
- ✅ **数据便携**：所有数据（用户 / 文件 / 配置 / 证书）保存在 exe 同目录 `data/`，删除文件夹即卸载
- ✅ GitHub Actions 自动构建发布（推送 `v*` 标签即出 Release）

## 🚀 快速开始

### 方式一：Windows 绿色版（免安装）
1. 在 [Releases](https://github.com/hrk666666/lancloud/releases) 下载 `LanCloud-vX.X.X-win64.zip`
2. 解压，双击 `LanCloud.exe`（**使用 DNS 域名定向请右键 → 以管理员身份运行**）
3. 浏览器打开 `http://127.0.0.1:8080`，登录 `admin / admin123`

### 方式二：源码运行
环境要求：Python 3.9+

```bash
# Windows
start.bat

# macOS / Linux
./start.sh
```

首次登录后请尽快在「管理面板 → 系统信息」中修改密码（或编辑 `data/config.json` 的 `admin_password` 后重启）。

> 局域网其他设备访问：`http://你的IP:8080`（启动时终端会打印所有可用地址）

## 📖 使用教程

### 网盘基础操作
| 操作 | 方法 |
| --- | --- |
| 上传 | 右上角「上传」按钮，或直接把文件拖进页面 |
| 预览 / 编辑 | 双击文件（图片/视频/音频/文本/PDF 可预览，文本可编辑） |
| 下载 / 打包 | 悬停文件卡片点击图标；「打包下载」可将目录打包为 zip |
| 分享 | 点击分享图标 → 可选"需登录 / 有效期" → 生成链接 |
| 共享文件夹 | 左侧「共享文件夹」浏览管理员共享的本机目录 |
| 移动 / 删除 | 列表视图操作；删除进入回收站（可恢复） |

### 域名定向（让 pan.lan 直达你的网盘）
打开「管理面板 → 劫持向导」按四步操作，或看 [docs/域名定向教程.md](docs/域名定向教程.md)。

速览：
1. 管理面板 → 域名定向，添加映射：`pan.lan` → 你的局域网 IP
2. 在路由器「DHCP 服务器 → 首选 DNS」填你的 IP（或单台设备手动设置 DNS）
3. 运行「一键诊断」自测，然后其他设备打开 `http://pan.lan:8080` 直达网盘

设备完全零设置：用 `sudo python3 scripts/arp_hijack.py --all --yes`（Linux，需 root），
详见 [docs/ARP欺骗教程.md](docs/ARP欺骗教程.md)。

### 用户与配额管理
打开「管理面板 → 用户管理」：
- 单个创建：填用户名 / 密码 / 配额（MB，0 不限）→ 创建
- 批量创建：点「批量创建账号」，每行一个 `用户名 密码 [配额MB]`
- 编辑：改配额、重置密码；可禁用 / 启用账号（禁用后立即无法登录）
- 可分享开关：控制该用户能否创建分享链接

### 共享本地文件夹
打开「管理面板 → 共享文件夹」：填写共享名称与本机路径（如 `D:\Movies`、`/home/user/共享`），保存后所有用户可在网盘左侧「共享文件夹」中浏览 / 下载。

### 启用 HTTPS
打开「管理面板 → HTTPS」：
1. 填端口（默认 8443；要劫持 HTTPS 网站时填 443）
2. 点「启用 HTTPS」，重启 LanCloud 生效
3. 可选：下载 CA 证书安装到设备，消除证书警告（教程见页面内）

## 🐳 进阶：Docker 集成高分开源项目

LanCloud 自带完整网盘与 DNS，不开 Docker 也能使用。若想要"更强网盘 + 广告拦截"：

```bash
docker compose up -d
```

- **Alist**（`http://IP:5244`）：高性能网盘，支持本地存储 / WebDAV / 聚合网盘
- **AdGuard Home**（`http://IP:3000`）：DNS 过滤 + 广告拦截

> 注意：AdGuard Home 与 LanCloud DNS 都占用 53 端口，请二选一使用（或在 AdGuard 中改端口）。

## ⚠️ 重要说明（必读）

1. **HTTPS 限制**：DNS 只能决定"域名解析到哪个 IP"。目标站点是 HTTPS 时，浏览器会做证书校验并提示"证书不受信任"——启用自签名 HTTPS 后，点"高级 → 继续访问"仍可看到内容；安装本项目 CA 证书后可免警告。**静默无警告劫持 HTTPS 网站做不到**，这是 TLS 加密的设计保证；启用 HSTS 的站点（如 google.com）浏览器会直接拒绝。
2. **合法边界**：域名定向/劫持是双用途技术，**只应在你自己拥有或已获授权的网络和设备上使用**。在中国，未经授权截获 / 劫持他人网络流量违反《网络安全法》和《刑法》第 285/286 条，用于钓鱼盗号属于犯罪。本项目不提供任何针对第三方网站的钓鱼能力，请合理使用。
3. **DNS 端口**：53 端口是特权端口。Windows 需以管理员身份运行；Linux/macOS 需 `sudo` 启动或设置 `setcap cap_net_bind_service=+ep`。若 DNS 启动失败，网盘功能不受影响。
4. **劫持不生效时**：先在「管理面板 → 劫持向导 → 一键诊断」自测；再看「查询日志」——若没有任何查询记录，说明设备 DNS 还没指向本机，按教程配置路由器或设备 DNS。
5. **备份**：所有数据在 `data/` 目录，备份时整体复制即可。

## ❓ 常见问题

见 [docs/常见问题.md](docs/常见问题.md)。

- 局域网设备打不开网盘？→ 确认同一 WiFi / 防火墙放行 Web 端口
- DNS 启动失败？→ 端口被占用或权限不足，见上方"重要说明"
- 想改端口？→ 编辑 `data/config.json` 或 `LANCLOUD_PORT=9000 python run.py`
