Windows 下端口 53 需要管理员权限：请右键 LanCloud.exe → 以管理员身份运行。若仍失败，通常是端口被占用或防火墙拦截（见下方诊断）。

2

添加域名映射（劫持目标）

把你要劫持的域名指向目标 IP（通常填本机 IP，即网盘所在设备）。示例：pan.lan → 192.168.1.100。完成后点「域名定向」标签页添加。

3

让局域网设备把 DNS 指向本机

这是"一个链接覆盖全网"的关键。二选一：

  • 推荐：改路由器 DHCP（一次配置，所有设备自动生效，无需逐台设置）——见「接入教程」方式一
  • 单台设备手动设置 DNS——见「接入教程」方式二

注意：只改路由器 DNS 不够，还要在「域名定向」里添加映射，两者配合才完整。

C

方案 C（Windows 专属）：全自动接管 —— 设备一个设置都不用做

自动安装内置内核驱动（WinDivert，无需下载），本机向全网广播"网关是我"， 同 WiFi 下所有设备的 DNS 查询自动送到本机，被劫持域名直接打开你的网盘， 其他网站照常上网。停止后自动广播恢复，设备无需任何操作。

使用前提：本机以管理员身份运行、与目标设备同一局域网。首次需在「域名定向」添加劫持映射。

①

访问自己的网盘（HTTPS）

启用并重启后，可通过 https://127.0.0.1:端口 或 https://局域网IP:端口 访问。浏览器警告属正常，安装 CA 证书后消失。

②

劫持 HTTPS 网站

设备访问 https://目标域名 时默认连 443 端口，所以把 HTTPS 端口设为 443（需管理员权限）并启用后，劫持 HTTPS 站点可显示你的内容（浏览器会有证书警告；启用了 HSTS 的站点如 google.com 无法劫持，浏览器会直接拒绝）。

③

安装 CA 证书（可选，消除警告）

  • Windows：下载 CA 证书 → 双击 → 安装证书 → 本地计算机 → 受信任的根证书颁发机构
  • Android：设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书
  • iOS：下载后到 设置 → 通用 → VPN 与设备管理 安装，再在"关于本机 → 证书信任设置"中启用完全信任
注意：启用 HTTPS 需重启 LanCloud 生效。HTTPS 与 HTTP 可同时提供服务，互不影响。
下面是三种接入方式，选一种即可。都不需要对方设备安装任何软件或信任证书（HTTP 场景）。
1

原理：DNS 是怎么"劫持"的

设备访问 pan.lan 时先问"DNS 服务器：pan.lan 在哪？"。你的服务回答说"在我这里（你的 IP）"，于是设备就直接连到了你的网盘。DNS 只管解析，设备端完全无感知。

2

方式一：路由器设置（最推荐，一次配置全家生效）

  1. 登录路由器管理页（常见 192.168.1.1 或 192.168.0.1）
  2. 找到「DHCP 服务器」→「首选 DNS 服务器」
  3. 填入本机 IP：正在获取…，保存并重启设备网络
  4. 之后全家人任何设备访问 pan.lan 都会直达你的网盘
3

方式二：单台设备手动设置 DNS（不改路由器）

  • Windows：设置 → 网络和 Internet → 更改适配器选项 → 双击网卡 → IPv4 属性 → 首选 DNS 填本机 IP
  • macOS：系统设置 → 网络 → 详细信息 → DNS → 添加本机 IP
  • 手机（Android/iOS）：WiFi 详情 → 修改网络 → IP 设置改为静态 → DNS 填本机 IP
4

方式三：手机开热点（设备连热点即可劫持）

如果不想动路由器：本机开手机热点，把 DNS 服务端口改为 53，其他设备连这个热点并把 DNS 指到本机 IP 即可。适合临时演示。

5

重要限制（必读）

  • HTTP 网站：可被无缝解析到你的服务，设备端直接看到你的内容。
  • HTTPS 网站：浏览器会提示"证书不受信任"，因为你的服务没有对方的证书。启用自签名 HTTPS（见 HTTPS 标签页）后，点"高级 → 继续访问"仍可看到内容；静默无警告劫持 HTTPS 做不到——除非每台设备安装你的 CA 证书。
  • 合法边界：只在你自己的网络和设备上使用。未经授权劫持他人流量违反中国《网络安全法》和《刑法》，用于钓鱼盗号属于犯罪。
